# Robin Card

## Local

```bash
npm install
npm run dev
```

Open http://localhost:3000

## GitHub → Railway (live)

1. Push this repo to GitHub (`main` branch). Do not upload `node_modules` or `dist`.
2. On [Railway](https://railway.app): **New Project** → **Deploy from GitHub repo** → select this repo.
3. Wait for the deploy to succeed.
4. Open the service → **Settings** → **Networking** → **Generate Domain**.
5. Open the `*.up.railway.app` URL. The site should load.

No environment variables are required.

Admin login: `admin` / `SuperAdmin@2026`
